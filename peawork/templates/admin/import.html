How the import works

  • All or nothing: a single bad row rolls back the whole file.
  • Managers second: reporting lines are resolved after every employee exists, so rows can reference later rows.
  • Auto-create: unknown departments and positions are added using the spreadsheet value as the name.
  • Duplicates: employee numbers and work emails must be unique, both in the file and the database.
  • Audit: successful imports are recorded with the filename and counts.
